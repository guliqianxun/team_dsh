# Team DSH

[English](README.md)

DSH 界面里的历史复盘小宠物。点击宠物，按标题找到对话，勾选 1—3 个，点击“开始复盘”。结果在新的原生对话中显示，可以继续追问；原对话不会被改写。

默认使用社区鲸鱼娘。在“外观”中可切换小猫或选择不超过 1 MiB 的 PNG、JPEG、WebP 图片。选择保存在当前浏览器，刷新后保留；清除网站数据会重置外观。图片不上传给模型。

DSH 原生引用在消息开始处理时捕获历史，已压缩或过长的对话可能只提供摘要或部分内容。复盘先说明工作与可见结果，再给出有效做法、受阻点及最多三条有证据的改进。结果区分用户确认、助手自述和尚未验证；每条建议说明适用情形、具体做法及下一次同类任务的验证办法，确有依据时附一段可复制的提示词或项目约定草案。短对话或证据不足时简短说明，不编造模式。复盘使用当前实例的默认模型和原生权限，通过 Team DSH 专用模式运行；该模式只挂载原生只读市场工具，普通复盘不调用工具；勾选工具建议时仅允许只读市场检索，不自动应用方案。

选中的对话内容和测量数据会发送给当前配置的模型服务，产生正常模型用量。预览版还会在复盘消息中记录工具次数、显式错误、调用到结果的耗时、未结束调用，以及供应商报告的 token/cache 用量。未知值保持未知，恢复记录不代表工具失败。每个来源附有统计截止点和事件序号，在宠物列表点击该来源旁的“查看对话”，再打开“轨迹”即可核对。明细展示每个来源的前 100 条工具调用和 100 条模型用量记录，汇总覆盖完整日志；另从完整日志保留显式错误、未结束调用、耗时最长调用及已报告总 token 最高样本，每类最多五条。排序不证明浪费、费用或原因；缺少总 token 的样本不参与该排序，仍计入缺失统计。文字引用稍后捕获，截止点可能不同。更多来源的分批摘要和摘要复用尚未实现；已发布的 `v0.1.0-alpha.1` 标签仍只提供文字复盘。

需要结合工具改进协作时，在“开始复盘”前勾选“同时给出工具建议”；默认不勾选，无需填写关键词。模型先从所选历史识别任务需要，区分已观察到的缺口、有依据但待验证的可能缺口与可选增强，再自行提炼关键词，通过 DSH 原生只读 `plugin_market` 工具检索。报告围绕需要说明可能欠缺什么、先尝试哪些已有能力或方法，以及互补插件如何配合；同类插件作为替代项，一个插件足够或无需插件也可成立。候选限于已配置市场实际返回的兼容版本，发布者声明及工具互通效果仍需验证。检索词、调用和结果留在同一原生对话与轨迹中。使用检索前需启用“自定义插件市场”并在 Discover 配置索引；不可用或失败时仍复盘已有证据，并明确说明推荐限制。查看和安装候选由用户在原生 Discover 操作。

已有任务清单继续保留：一句话创建任务，点击进入原生对话，人工勾选完成或取消完成。

任务保存名称、完成状态和主 Session 关联。聊天、模型、权限和轨迹由 DSH 提供。打开任务只准备或恢复对话，发送消息才运行模型；对话结束不会自动完成任务。

## 安装

`0.1.0-alpha.2` 预览版面向 DSH `0.2.1-rc.2`，包含构建文件，无需本机编译或运行安装脚本。安装到 Web profile：

```sh
dsh plugin --profile web add team-dsh@0.1.0-alpha.2 --ignore-scripts
```

随后按原来的方式启动该 profile。点击悬浮宠物开始复盘，侧栏 **Team DSH** 打开任务清单。问题与建议请提交到 [GitHub Issues](https://github.com/guliqianxun/team_dsh/issues)。

Desktop 需先启动一次以初始化 profile，再完全退出应用后安装。如果 PATH 中没有 `dsh`，使用 Desktop 自带的命令：

```sh
dsh plugin --profile desktop add team-dsh@0.1.0-alpha.2 --ignore-scripts
```

安装后重新打开 Desktop。Web 已完成实测，Desktop 尚未实测。把固定版本换成 `team-dsh@next` 可安装当前 npm 预览版。安装插件不会迁移其他设备的历史对话。

也可启用 DSH 的实验功能“自定义插件市场”，在 Discover 添加索引源：`https://raw.githubusercontent.com/guliqianxun/team_dsh/main/market/index.json`。这是本项目提供的索引；其他社区市场的收录由各自维护者决定。

## 开发

需要 Node `^22.19.0 || >=24.0.0`、npm 和 DSH `0.2.1-rc.2`。

```sh
npm ci
npm test
npm run build
npm pack --ignore-scripts
```

将生成的预览包加入自己的 DSH profile：

```sh
dsh plugin --profile <profile> add ./team-dsh-0.1.0-alpha.2.tgz --ignore-scripts
```

公开发行提交需要同时包含当前 `lib/` 构建文件。包没有安装或打包生命周期脚本，发布前显式运行上述测试与构建。

## 从哪里读代码

| 位置 | 职责 |
| --- | --- |
| `src/index.ts` | Host 加载与释放 |
| `src/tasks/` | 保存任务、打开关联 Session、接收页面请求 |
| `src/history/` | 仅限 owner 的所选日志统计 |
| `src/shared/` | 页面和 Host 共用的任务及统计字段 |
| `src/client/` | 悬浮宠物、对话选择与发送、任务清单 |
| `tests/` | 数据保留、对话关联、页面操作 |

[架构](docs/architecture.md)说明消息和数据如何流转。日常修改只运行测试和构建，不要求维护教案或同步台账。

## 从旧版升级

升级前备份 DSH 数据目录。已有任务和主对话继续保留；旧“进行中”任务在最小清单中视为未完成。旧目标编辑、执行、成果、评审、分析员工具和自动任务上下文注入已移除，旧记录保留但不再提供这些操作入口。旧未完成的首发绑定需回到历史版本处理，本版不重发、不替换其 Session。

用户教学目录与本机 Session 不删除。项目代码采用 [MIT](LICENSE) 许可。
